Q1 PINNACLE-CODING-1 · SSC CPO 2019
In a code language, BANKER is written as NABREK. How will STRING be written as in that language?
एक कूट भाषा में BANKER को NABREK लिखा जाता है। उसी भाषा में STRING को कैसे लिखा जाएगा?
A) RSTGI
B) RTSGNI ✓
C) TSIRGN
D) RTGSNI
Answer / उत्तर: B
Solution / हल
EN: The six-letter word is split into two groups of three letters, and the letters within each group are reversed. Check: BANKER -> BAN|KER -> reverse each group -> NAB|REK -> NABREK. Apply the same to STRING -> STR|ING -> reverse each -> RTS|GNI -> RTSGNI. Hence the answer is (B) RTSGNI.
HI: छह अक्षरों के शब्द को तीन-तीन अक्षरों के दो समूहों में बाँटकर, प्रत्येक समूह के अक्षरों को उल्टा कर दिया जाता है। जाँचें: BANKER -> BAN|KER -> प्रत्येक समूह उल्टा -> NAB|REK -> NABREK। यही नियम STRING पर लगाएँ -> STR|ING -> उल्टा -> RTS|GNI -> RTSGNI। अतः सही उत्तर (B) RTSGNI है।
Q2 PINNACLE-CODING-2 · SSC CPO 2019
If CAB = 12 and FED = 30, then HIDE =____.
यदि CAB = 12 और FED = 30 है, तो HIDE = ____ होगा।
A) 44
B) 68
C) 52 ✓
D) 48
Answer / उत्तर: C
Solution / हल
EN: Each letter is replaced by its position in the alphabet (A=1, B=2, ...) and the sum is doubled. Check: CAB = 3+1+2 = 6, and 6x2 = 12. FED = 6+5+4 = 15, and 15x2 = 30. For HIDE = 8+9+4+5 = 26, so 26x2 = 52. Hence the answer is (C) 52.
HI: प्रत्येक अक्षर को वर्णमाला में उसकी स्थिति (A=1, B=2, ...) से बदलकर योग को दोगुना किया जाता है। जाँचें: CAB = 3+1+2 = 6, और 6x2 = 12। FED = 6+5+4 = 15, और 15x2 = 30। HIDE = 8+9+4+5 = 26, अतः 26x2 = 52। सही उत्तर (C) 52 है।
